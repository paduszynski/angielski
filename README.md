# Angielski

Fiszki z angielskiego dla dzieci (2 klasa): https://paduszynski.github.io/angielski/

Moduły:
- **Fiszki**: zdjęcie, słówko i wymowa (synteza mowy en-GB). Trzy tryby: zdjęcie → słówko, słówko → zdjęcie, posłuchaj i zgadnij. Błędne fiszki wracają w tej samej rundzie, postęp zapisuje się w przeglądarce.

Słówka: zwierzęta na farmie i małe zwierzątka. Nowe słówko = wpis w `WORDS` w `index.html` + zdjęcie 640×480 w `img/<słowo>.webp` (+ autor w `CREDITS` i ścieżka w `sw.js`).

Cała strona to jeden plik `index.html` (GitHub Pages z gałęzi `master`). Zdjęcia z Wikimedia Commons, autorzy i licencje są w stopce strony.
